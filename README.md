# AI Engineering Assessment Studio

Starter repository for the AI Engineering date-fruit training and five-hour assessment workstation.

Start with [Architecture v1](docs/ARCHITECTURE_V1.md) and [Source inventory](docs/SOURCE_INVENTORY.md). This starter contains the specification and project rules; the integrated application has not been implemented yet.

## Repository setup on Windows

1. Extract the starter archive into a working folder, for example `C:\Projects\ai-engineering-assessment-studio`.
2. Install Git and sign in to GitHub using GitHub Desktop or GitHub CLI, or configure command-line Git authentication.
3. Initialize Git in this folder, commit the starter, then publish a **private** GitHub repository named `ai-engineering-assessment-studio`. See the final handoff instructions for exact commands.
4. Bring the current prototypes into `legacy/` only after checking version and provenance. Do not commit datasets, trained weights, credentials or hidden test images.
5. Begin M1 as a separate implementation task; follow `AGENTS.md` and the acceptance gates in the architecture.

The sample package has no live robot credentials, API keys, copyrighted dataset payload, or candidate data.
